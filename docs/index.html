M365 Model Selector

Browser extension that automatically selects GPT 5.5 Think Deeper on Microsoft 365 Copilot Chat — every time, no clicks required.

  1. 1 Download the extension zip file below
  2. 2 Extract the zip to a folder on your computer
  3. 3 Go to chrome://extensions, enable Developer mode (top right)
  4. 4 Click "Load unpacked" and select the extracted folder
  5. 5 Navigate to M365 Copilot Chat — the model switches automatically
